      OpenAlex-Schlüssel

      Abgleich (iPad ↔ PC)

      Einrichtung in 5 Schritten
      1. Auf GitHub ein neues privates Repository anlegen, z. B. journalbing-daten, mit Haken bei „Add a README“.
      2. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
      3. Bei „Repository access“ nur dieses eine Repository wählen. Unter Permissions → Repository permissions → Contents: Read and write einstellen.
      4. Den Schlüssel kopieren und oben einfügen, dazu den Repository-Namen (dein-name/journalbing-daten).
      5. Auf jedem Gerät einmal einrichten. Danach reicht „Jetzt abgleichen“.

      Der Abgleich fügt zusammen: Was auf einem Gerät neu ist, kommt aufs andere. Entfernte Paper kommen beim nächsten Abgleich vom anderen Gerät zurück, solange sie dort noch gespeichert sind. Der Schlüssel liegt nur in diesem Browser. Lege ihn nie in das öffentliche JournalBing-Repository.

      Sammlungen sichern

      Deine Sammlungen liegen nur in diesem Browser. Mit Export und Import ziehst du auf ein anderes Gerät um oder legst eine Sicherung an.
